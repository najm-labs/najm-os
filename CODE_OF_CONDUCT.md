# Code of Conduct

## Our Standard

Najm OS is a technically ambitious project that depends on contributions from people with wildly different backgrounds — kernel engineers, driver authors, security researchers, and newcomers writing their first line of Rust. That only works if the project is a place people want to keep showing up to.

We hold contributors to one standard: **engage with the work in good faith, and treat the people behind it with respect.**

## Expected Behavior

- Critique code, designs, and ideas directly and rigorously — this is a systems project and technical disagreement is normal and welcome.
- Keep criticism focused on the technical substance, not the person who wrote it.
- Assume good faith from newcomers; explain *why*, not just *what's wrong*.
- Respect maintainers' time: search existing issues/RFCs before opening new ones, and keep discussion on-topic.

## Unacceptable Behavior

- Personal attacks, harassment, or discriminatory language or jokes, in any project space (issues, PRs, discussions, chat).
- Deliberately submitting malicious code (backdoors, credential exfiltration, intentional security holes) — given this is kernel code, this is treated as a severe violation, not a prank.
- Sustained disruption of discussions or reviews.
- Publishing others' private information without consent.

## Scope

This applies to all project spaces — GitHub issues, pull requests, discussions — and to any other space where someone is representing the project.

## Enforcement

Violations can be reported by opening a confidential report to the maintainers (contact method to be added once the project has a dedicated security/conduct email). Reports will be reviewed and addressed proportionally: a first offense typically gets a direct, private warning; repeated or severe violations result in removal from project spaces.

Maintainers reviewing conduct reports will recuse themselves from cases where they're personally involved.

## Attribution

This Code of Conduct is intentionally short and specific to this project rather than a generic template — it will be expanded as the contributor base grows and real situations require clearer guidance.
